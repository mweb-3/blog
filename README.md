# blog

this site was originally made for my mom to make communication easier after she had a medical emergency and was constantly copy-and-pasting the same text message to several group chats, all with different people

i took this as a learning opportunity and decided to make a website where she could write and post these updates where anyone can see it and leave a reply. i never ended up showing her because she didnt really end up needing it, so i turned it into just a regular blog website. unfortunately i dont have anything to write long form about so I'm just open sourcing it
